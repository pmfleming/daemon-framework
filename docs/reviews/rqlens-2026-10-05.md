# RQLens review — 2026-10-05

Baseline: `aec7301`. This pass targets the framework, not RQLens. The largest
remaining actionable hotspots were in the recently imported native local-build
utility; shared runtime crates were reviewed but their public APIs were retained.

## Changes

- **Snapshot copying:** tracked and frozen trees share `copy_leaf` for regular
  files, symlinks, metadata preservation and unsupported-entry rejection. Both
  paths now check regular-file size/mtime stability. Tracked symlink confinement,
  ignored/untracked-file policy, permissions and dangling/internal links remain
  intact. Frozen-tree symlinks are still copied without rewriting their targets.
- **Process reuse:** one `command` module owns checked process execution for Git,
  Nix and CLI invocations. It replaces the duplicate Git status/output handling;
  stderr inheritance and nonzero-status propagation are retained.
- **Policy locality:** CLI dispatch delegates lock-file pruning to `lock` instead
  of knowing about filesystem resolution, input selection and serialization.
  Repository policy checks are separated from root-wide follow relationships.
- **Ownership:** captured input maps use `Rc<Inputs>` in the single-threaded build
  utility. Repeated graph edges share them; `Rc::make_mut` copies only for an
  overlaid edge. Nested input validation borrows maps instead of recursively
  cloning JSON. URL authority parsing borrows slices instead of building strings.
- **Lock traversal:** follows paths, node names and cycle-trail entries borrow the
  immutable lock document. Only the final retained-name set owns its names;
  missing edges and follows cycles still fail closed.
- **Regression reuse:** command-socket fixtures serve both UTF-8 and malformed
  replies. Partial-read cancellation and oversized-frame/backoff cancellation
  share one parameterized test without losing either scenario. Added overlay
  isolation/borrow checks and extended frozen-copy metadata assertions.

No production API, dependency, source pin, lint allowance, safety boundary or
quality threshold was removed or relaxed. Redundant implementations were
removed, but this is **not** a whole-program dead-code elimination claim. An
uncalled public library API cannot be assumed dead in this workspace alone.

`snapshot::snapshot` itself falls from 18 to 13 cyclomatic, 8 to 4 cognitive,
and 73,933.51 to 55,031.95 Halstead effort. The new leaf helper is included in
aggregate function metrics. Not every function improves: copy-on-write edge
handling raises `Graph::walk` from 11/6 to 12/7 cyclomatic/cognitive; borrowing
adds explicit lifetime syntax to lock resolution. Those are accepted ownership
trade-offs, not hidden improvements.

Reuse improves through shared process/copy implementations. Locality's tiny
average increase comes from adding an already-local module to a saturated
inventory; existing module scores do not improve. Do not present that as a
substantial architectural-score gain. Total LOC reduction is also small after
regression coverage. The remaining AST clone is coincidentally similar Display
implementations for different error domains; combining them would obscure policy.
