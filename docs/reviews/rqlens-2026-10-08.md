## Findings and refactors

- **Preflight traversal was the largest production hotspot.** `Scan::walk`
  mixed discovery, cached evaluation, diagnostics and overlay handling. Cached
  maps were deeply cloned for each distinct edge overlay. Evaluation now lives
  in `Scan::inputs`, including cached failures; one diagnostic helper handles
  repository and edge errors without allocating diagnostic paths on success.
  Cached definitions use `Rc<Inputs>`. Preflight and snapshot traversal share
  `policy::overlaid`, which copies only for overlays, preserving edge isolation.
  The serialization `expect` now propagates errors.
- **Directional geometry repeated axis calculations.** Monitor geometry now
  normalizes the search axis after rotation/scaling; all directions reuse one
  adjacency/overlap calculation. First-candidate tie breaking, disabled-monitor
  filtering and the strict two-unit adjacency threshold are retained.
- **Pending-event delivery unnecessarily rebuilt its queue.** Activation now
  returns the partitioned queue directly, removing the tuple conversion and
  second collection before delivery. Ordering, buffering bounds and terminal
  suppression remain unchanged.
- **Cancellation coverage had overlapping fixtures.** One parameterized test
  covers routed and legacy cancellation failures, successful cancellation
  responses, late-event suppression and reset. Its obsolete `render` helper and
  separate legacy-only test are removed. Geometry assertions share a helper;
  new cases cover all six direction names and rotated/scaled monitors. Extended
  preflight tests verify shared-map identity and cached evaluation failures
  across distinct overlays.

No public API, dependency, admission bound, lint allowance, source policy or
quality threshold was changed. No unused private production symbol was proven
removable; public APIs cannot be declared dead from workspace-only usage. This
is removal of redundant implementations/fixtures, not whole-program dead-code
elimination.

Leverage improves structurally through reuse of overlay handling and diagnostics,
but **neither architecture score improves**. Existing locality is near its
ceiling; library facade dependencies should not be hidden to raise it. Net LOC
reduction is small after regression coverage. The remaining AST clone compares
Display implementations for distinct error domains; combining them is not useful.

Cloning improvement is about ownership cost: preflight no longer deep-clones
unoverlaid cached JSON maps. The summary's method-only clone count (50 to 49)
is not evidence of fewer clone invocations: it excludes the explicit `Rc::clone`
notation now used in `graph`. Reference-count increments and necessary overlay
copies remain. No allocation benchmark was run.
