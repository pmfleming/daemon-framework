## Findings and changes

- **Watch planning was the main complexity outlier.** In
  `shelllist-daemon-core/src/watch.rs`, replace two path sets with one map that
  records whether a registered path has been expanded. Drain the traversal stack
  before lazily requesting another root, rather than nesting two traversal loops.
  Share the registration/queued-directory budget check. This eliminates one
  owned path clone per recursive visit and the second tree of owned paths.
  Nonrecursive roots still permit later recursive expansion; repeated recursive
  roots are not expanded again. Extend the existing test across those orderings.
  Sorting, descendant-symlink exclusion, bounded queuing and errors are retained.
- **Protocol rendering mixed identifier parsing with output assembly.** In
  `shelllist-daemon-core/src/bin/shelllist-protocol-js.rs`, isolate QML identifier
  grammar, return early for untyped registries, and select validation source and
  call prefix together. Add identifier boundary assertions. No generated output
  or CLI behavior changes in the differential checks below.
- **Timing assertions were duplicated across transport fixtures.** Share
  `within_seconds` in the existing `transport_tests.rs` fixture module, retaining
  each caller's original deadline. Expected timeout assertions remain explicit.
  This removes one RQLens token-clone group without deleting test scenarios.
- **Small avoidable decision/allocation costs:** use inclusive byte-length ranges
  in `service.rs`; use borrowed JSON object keys instead of allocating and parsing
  JSON pointers in local-build's `policy.rs`.
- **Escape hatches:** replace the two test wildcard imports in `state.rs` and
  `watch.rs` with explicit imports. No unsafe code, suppression, dependency or
  macro-based metric hiding was introduced.

No public API was removed. Strict Clippy found no unused-code warnings after the
changes; that is not proof of whole-program liveness. No safely removable dead
production API was established, and sibling consumers were not revalidated.
The remaining clone groups include small error-formatting implementations and
similar but independently useful tests; they were not forced into abstractions.
