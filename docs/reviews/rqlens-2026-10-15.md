# Focused Rust quality review

Measured with the local `../rust-quality-lens/target/debug/rqlens`, using the
unchanged `rqlens.toml`. Baseline artifacts are in `target/refactor-review/`;
final artifacts are in `target/analysis/` (both ignored build outputs).

## Findings and changes

- **Protocol generator:** `render` mixed registry validation, schema traversal,
  contract copying and rendering. Separate method/event extraction now borrows
  schemas until serialization, preserving sorted output and optional contracts.
  Recursive schema validation uses the same traversal for every child in a
  map/array, without nested explicit loops.
- **Service boundary:** reuse `task::AbortOnDrop` instead of a second guard
  implementation; pass the admission lane explicitly instead of a boolean.
  Missing execution policy now rejects before polling work instead of panicking.
  Encoding failures retain the existing outcome-unknown envelope.
- **Event forwarding:** serialize the typed envelope directly, avoiding an
  intermediate JSON tree; propagate serialization errors instead of expecting.
- **JSONL framing:** simplify EOF completion without changing bounded allocation,
  CRLF handling, oversized-record draining or cancellation safety.
- **Test ownership:** colocate policy tests beneath the service test module and
  share rejection helpers. Replace all five wildcard imports with explicit imports.

No exported symbols were removed. Sibling daemons consume this library, so a low
workspace-local consumer count is not sufficient evidence of dead code. Strict
compiler/Clippy checks found no unused private items. Duplicate implementations
were removed rather than introducing a general abstraction for unrelated policies.

Locality is preserved, not numerically improved. Remaining duplication includes
small independent error displays and domain-specific test scenarios; sharing them
solely to lower a score would harm locality. No lint suppressions or dependencies
were added.

## Validation and limits

- `cargo fmt --all --check`
- `cargo clippy --workspace --all-targets --locked -- -D warnings`
- `cargo test --workspace --locked`: 88 tests passed (baseline: 87).
- Differential generator check: 216 valid/invalid inputs produced identical
  stdout and acceptance/rejection against HEAD's generator, including direct and
  wrapped registries, duplicate names, absent contracts and nested schemas.
  Reproduction script/baseline executable: `target/refactor-review/`.

Regenerate the focused evidence with:

```sh
for metric in hotspots clones escape-hatches reliability locality leverage; do
  ../rust-quality-lens/target/debug/rqlens measure "$metric" --config rqlens.toml
done
```

RQLens reports a partial syntax inventory because it cannot expand the
`declare_methods!` invocation. Both fingerprints also report incomplete Cargo
project/helper path dependency resolution. These are comparative advisory
measurements, not proof of complete macro coverage, absence of panics or runtime
performance gains. Consumer builds, coverage and deployment/Nix checks were not
run. The existing advertised-MSRV mismatch remains: validation uses Rust 1.95,
not the manifests' 1.85.
