Ranked findings and implemented work
1. events::CompositorEvent::parse: largest production cognitive hotspot (33).
   Unified malformed-data fallback using a local fallible parsing scope, replaced
   repeated failure branches, removed open-window temporary Vec allocation, and
   parsed workspace numbers once. Exact names, unknown events, raw malformed
   fields, legacy/v2 payloads and all identity rejection guards remain intact.
2. lib::forward_events: cognitive 18; duplicated full/closed send handling.
   Shared try_send_event retains unsent error identity and distinguishes full
   queues from closed receivers. Pending Lagged, idle delivery, partial-read
   preservation, bounds, cancellation and reconnect timing remain unchanged.
3. WindowAddress: event conversion formatted then copied a pointer solely to
   normalize it. Shared crate-private from_digits keeps validation next to its
   data, rejects invalid digits before allocating and normalizes in one buffer.
   This removes a temporary allocation, not a .clone() call or public API.
4. Tests: combined three overlapping move tests into one identity matrix; added
   missing/truncated fields, zero/oversized/nonhex pointers across five event
   shapes, invalid IDs, raw malformed fields, missing separators and empty valid
   payloads. Existing exact-name, captured-event and real socket/loss tests remain.
   Replaced two test wildcard imports with explicit imports. No new panic,
   unsafe, allow or lint suppression was introduced.
5. Remaining production hotspots reviewed: Client::connect (cognitive 13),
   socket::connection (13), reconnect_events (12), bounded_watch_paths (9),
   local-build lock/prune and policy traversal (6). Their ownership, bounds,
   retry and security branches are meaningful and were retained. Clone candidates
   in short Lua builders encode different guarded commands; merging them behind
   string parameters would weaken locality/type intent. Private compositor
   acceptance is the largest test hotspot (cognitive 53) and needs its renderer.
